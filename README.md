# Fritz Jenner Vitto — Personal Profile Website

A responsive dark/modern personal profile website built with HTML, CSS, and vanilla JavaScript.

## Preview locally
Open `index.html` in a browser. An internet connection is needed for the Google Fonts.

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub (for example, `fritz-personal-profile`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then Save.
6. Wait for GitHub Pages to publish. Your site URL will look like `https://YOUR-USERNAME.github.io/fritz-personal-profile/`.

## Before publishing
- Replace the `mailto:hello@example.com` address in `index.html` with your real public contact email, or remove the email button.
- Add social links if you want them displayed.
- The profile illustration is a placeholder. To use your own photo, replace the avatar placeholder block in `index.html` with an image element and add your image file to the repository.
- Review all wording and only publish contact details you are comfortable sharing publicly.

## QR code
After GitHub Pages gives you the final public URL, create a QR code that points to that exact URL. The QR code will open your website; it does not host the website itself.
